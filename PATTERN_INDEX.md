## Common comparisons

| Comparison | First unit | Second unit | Selection rule |
|---|---|---|---|
| Sliding window vs prefix sum | [DSA-SEQ-060](CURRICULUM.md#dsa-seq-060) | [DSA-SEQ-070](CURRICULUM.md#dsa-seq-070) | Use windows when validity changes monotonically as boundaries move; use prefix state for arbitrary fixed ranges or signed/non-monotonic sums. |
| Two pointers vs binary search | [DSA-SEQ-040](CURRICULUM.md#dsa-seq-040) | [DSA-ORD-010](CURRICULUM.md#dsa-ord-010) | Two pointers jointly eliminate pair candidates; binary search locates one ordered boundary or value. |
| BFS vs DFS | [DSA-GRA-020](CURRICULUM.md#dsa-gra-020) | [DSA-GRA-030](CURRICULUM.md#dsa-gra-030) | BFS exposes unweighted distance layers; DFS exposes reachability, finishing, and recursive structure. |
| Heap vs sorting | [DSA-SQH-080](CURRICULUM.md#dsa-sqh-080) | [DSA-PY-040](CURRICULUM.md#dsa-py-040) | Use a bounded heap for streaming or small K; sort when complete order is useful and all input is available. |
| Greedy vs dynamic programming | [DSA-GRD-050](CURRICULUM.md#dsa-grd-050) | [DSA-DP-010](CURRICULUM.md#dsa-dp-010) | Greedy needs a safe irreversible choice; DP preserves enough state when future value depends on earlier choices. |
| Backtracking vs dynamic programming | [DSA-REC-070](CURRICULUM.md#dsa-rec-070) | [DSA-DP-010](CURRICULUM.md#dsa-dp-010) | Backtracking explores path-specific choices; DP merges repeated states with identical future consequences. |
| Union-find vs graph traversal | [DSA-GRA-090](CURRICULUM.md#dsa-gra-090) | [DSA-GRA-040](CURRICULUM.md#dsa-gra-040) | DSU excels at incremental connectivity; traversal reveals component contents and paths. |
| Monotonic stack vs heap | [DSA-SQH-030](CURRICULUM.md#dsa-sqh-030) | [DSA-SQH-070](CURRICULUM.md#dsa-sqh-070) | A monotonic stack resolves ordered nearest relationships; a heap returns global priority without adjacency. |
| Memoization vs tabulation | [DSA-DP-020](CURRICULUM.md#dsa-dp-020) | [DSA-DP-020](CURRICULUM.md#dsa-dp-020) | Memoization follows reachable recursion; tabulation makes dependency order and space optimization explicit. |
| Trie vs hash map | [DSA-TRE-090](CURRICULUM.md#dsa-tre-090) | [DSA-PY-020](CURRICULUM.md#dsa-py-020) | A trie shares prefixes and supports prefix traversal; a hash map gives direct whole-key lookup. |
| Shortest-path algorithm selection | [DSA-GRA-100](CURRICULUM.md#dsa-gra-100) | [DSA-GRA-110](CURRICULUM.md#dsa-gra-110) | Weight domain and query shape determine BFS, 0-1 BFS, Dijkstra, Bellman-Ford, or all-pairs methods. |
| Bridges/articulation points vs SCC | [DSA-GRA-150](CURRICULUM.md#dsa-gra-150) | [DSA-GRA-150](CURRICULUM.md#dsa-gra-150) | Undirected low-link tests ask whether an edge or vertex disconnects a graph; directed SCC algorithms group mutually reachable vertices and use different parent/back-edge rules. |

## Anti-signals

- A pattern label seen on a website is not evidence that the pattern is correct for a changed constraint.
- Signed values often break sum-based variable-window monotonicity.
- A nested loop can still be linear when pointers only advance globally.
- Sorting may destroy streaming or original-order requirements.
- A heap does not provide nearest-neighbour order.
- Greedy intuition without an exchange, stays-ahead, cut, or invariant argument remains a hypothesis.
- Memoization does not repair a state definition that omits information needed by the future.
